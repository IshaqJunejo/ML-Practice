## Structure

Each `Day-XX-*` directory represents a concept/topic. Inside, you’ll find:
- `.py` scripts implementing the concept.
- Output plots or visualizations *(sometimes)*
- Sample datasets *(sometimes)*
- A per-topic `README.md` that gives a qucik summary.

## Environment

If you want to try out any of the implementation in this repository, you can,
- Clone the repository,
``` bash
git clone https://github.com/IshaqJunejo/ML-Practice.git
```
- Navigate to your concerned implementation, and make sure you have installed dependencies using `pip`.
- And run the code.

## Notes

- This is mostly self-supervised learning from multiple sources (YouTube, and ChatGPT suggestions).
- `.py` scripts are used instead of `ipynb` notebooks due to personal preferences.
- The number of **Days** that you might see in the directory naming might be misleading if taken literally. Some "Day"s have taken more than a day, and some "Day"s have came after a lazy break.
